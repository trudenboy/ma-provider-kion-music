## Как внести вклад

1. Сделай форк репозитория
2. Создай ветку `feat/описание-изменений`
3. Внеси изменения и добавь тесты
4. Открой Pull Request в ветку `dev`

## Стиль кода

Проект использует [ruff](https://docs.astral.sh/ruff/) для линтинга и форматирования.

```bash
uv run ruff check .
uv run ruff format .
```
