Провайдер предоставляет доступ к **радиостанциям KION Music** на базе движка Rotor — того же, что стоит за «Моим миксом» и тематическими волнами в официальном приложении.

Доступ: **Browse → KION Music → Радио**

## Категории

### Персональные

Ваши персональные радиостанции из дэшборда Rotor. Формируются на основе истории прослушивания и предпочтений. Доступны только после накопления достаточной истории в аккаунте.

### Избранные миксы

Кураторские категории волн от редакции KION Music — готовые тематические подборки.

### AI Сеты

Коллекции радиостанций, сгенерированные AI на основе лендинговых блоков KION Music. Обновляются автоматически.

### Тематические станции

| Категория | Описание |
|:----------|:---------|
| **Жанры** | Рок, Джаз, Классика, Электроника, Хип-хоп и другие |
| **Настроение** | Расслабляющее, Грустное, Романтическое, Вечеринка и другие |
| **Активность** | Тренировка, Концентрация, В дороге, Утро и другие |
| **Эпоха** | 80-е, 90-е, 2000-е, Ретро |
| **Местное** | Региональные и языковые подборки |

## Как работают станции

Каждая станция — **бесконечный поток треков**, подобранных Rotor:

1. Провайдер запрашивает у Rotor API батч треков для выбранной станции.
2. При воспроизведении каждого трека отправляется feedback (start / end / skip) — Rotor улучшает следующие рекомендации.
3. При окончании батча автоматически загружается следующий.
4. Каждая станция ведёт независимое состояние.

## Отличие от Мой микс

| | Мой микс | Радиостанция |
|:--|:---------|:-------------|
| Персонализация | По вашему вкусу в целом | По выбранной теме/жанру/настроению |
| Доступ | Browse → Мой микс | Browse → Радио → _категория_ |
| Feedback | Да | Да |
