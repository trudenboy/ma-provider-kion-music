---

Провайдер предоставляет доступ к двум типам кураторских плейлистов KION Music: **Подборки** и **Миксы**.

Доступ: **Browse → KION Music → Для вас → Подборки / Миксы**

## Подборки

Подборки — это редакционные плейлисты, организованные по тематическим тегам.

| Категория | Теги |
|:----------|:-----|
| **Настроение** | Расслабляющее, Грустное, Романтическое, Вечеринка, Релакс, … |
| **Активность** | Тренировка, Концентрация, Утро, Вечер, В дороге, Послушать фоном, … |
| **Эпоха** | 80-е, 90-е, 2000-е, Ретро |
| **Жанры** | Рок, Джаз, Классика, Электроника, R&B, Хип-хоп, Топ, … |

### Динамическое обнаружение тегов

Список тегов не захардкожен — провайдер получает его через Landing API KION Music:

- Пустые категории (без плейлистов) скрываются автоматически.
- Новые теги появляются без обновления провайдера.
- Результаты кэшируются на 1 час.

## Миксы

Миксы — это сезонные плейлисты, формируемые алгоритмами KION Music.

| Микс | Когда доступен |
|:-----|:---------------|
| Зима | Декабрь–Февраль |
| Весна | Март–Май |
| Лето | Июнь–Август |
| Осень | Сентябрь–Ноябрь |
| Новый год | Декабрь–Январь |

Текущий сезонный микс определяется автоматически по месяцу и появляется в разделе рекомендаций (Discover) с обновлением каждые 6 часов.
