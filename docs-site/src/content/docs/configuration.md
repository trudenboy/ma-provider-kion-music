## Шаг 1 — Получите токен

Провайдер использует **X-Auth-Token** для авторизации в KION Music.

### Через браузер

1. Откройте [music.mts.ru](https://music.mts.ru) в браузере и войдите в аккаунт
2. Откройте **Инструменты разработчика** (Ctrl+Shift+I / Cmd+Option+I)
3. Перейдите на вкладку **Хранилище** (Firefox) или **Application** (Chrome)
4. В разделе **Local Storage** выберите `https://music.mts.ru`
5. Найдите ключ `ya_token` и скопируйте его значение

---

## Шаг 2 — Добавьте провайдер в Music Assistant

1. Откройте **Music Assistant → Настройки → Источники музыки**
2. Нажмите **«+ Добавить»** и выберите **KION Music**
3. Вставьте скопированный токен в поле **«X-Auth-Token»**
4. Выберите предпочитаемое **качество звука** (см. ниже)
5. Нажмите **«Сохранить»**
6. MA подключится к KION Music и начнёт синхронизацию библиотеки

---

## Параметры провайдера

| Параметр | По умолчанию | Описание |
|:---------|:-------------|:---------|
| **X-Auth-Token** | — | Токен авторизации. Обязательный. |
| **Сбросить авторизацию** | — | Очищает сохранённый токен для повторного входа. |
| **Качество звука** | Balanced | Уровень качества: Efficient / Balanced / High / Superb. Подробнее — [Качество звука](features/audio-quality/). |
| **My Mix — максимум треков** _(расш.)_ | 150 | Сколько треков загружается для плейлиста «Мой микс». Меньше → быстрее загрузка. Диапазон: 10–1000. |
| **Мне нравится — максимум треков** _(расш.)_ | 500 | Максимум треков в виртуальном плейлисте «Мне нравится». Большие значения замедляют загрузку. Диапазон: 50–2000. |
| **API Base URL** _(расш.)_ | `https://music.mts.ru/ya_proxy_api` | Базовый URL API. Менять только если KION изменит эндпоинт. |

Параметры, помеченные _(расш.)_, отображаются в режиме «Расширенные настройки».

## Если токен перестал работать

Токен может истечь через некоторое время. Симптомы: провайдер перестаёт воспроизводить треки или показывает ошибку авторизации.

**Решение:**

1. В MA откройте настройки провайдера KION Music
2. Нажмите **«Сбросить авторизацию»**
3. Получите новый токен по инструкции выше (Шаг 1)
4. Введите новый токен и нажмите **«Сохранить»**
