## Получение токена

Провайдер использует **X-Auth-Token** для авторизации в KION Music.

### Из мобильного приложения

1. Установи [KION](https://kion.ru) на Android/iOS
2. Войди в аккаунт
3. Используй [mitm-proxy](https://mitmproxy.org/) или аналогичный инструмент для перехвата заголовка `X-Auth-Token` из запросов к `api.music.kion.ru`

## Добавление провайдера в Music Assistant

1. Открой **Music Assistant → Настройки → Провайдеры**
2. Нажми **Добавить провайдер** и выбери **KION Music**
3. Вставь токен в поле **X-Auth-Token**
4. Нажми **Сохранить**
